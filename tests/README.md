# Mobile App React Native

## Overview
This repository contains the source code for the Mobile App built with React Native. The app provides a seamless user experience across both iOS and Android platforms.

## Features
- Cross-platform compatibility
- Responsive UI design
- State management with Redux
- Integration with RESTful APIs
- Push notifications support
- Offline storage with AsyncStorage

## Prerequisites
Before you begin, ensure you have met the following requirements:
- Node.js (v16 or higher)
- npm (v8 or higher)
- React Native CLI
- Xcode (for iOS development)
- Android Studio (for Android development)

## Installation
To install the project dependencies, run the following command:

```bash
npm install
```

## Running the App
To run the app on an iOS simulator, use the following command:

```bash
npx react-native run-ios
```

To run the app on an Android emulator, use the following command:

```bash
npx react-native run-android
```
